# 磨石 Whetstone 1.1.0 桌面版

這次更新處理兩件事：Windows 版改成獨立程式視窗；新增可調力度和範圍的「強力去紋理」，AI 模式也能串接這道處理。

## 使用方式

1. 解壓 ZIP 後雙擊 `Whetstone.exe`，或直接執行 EXE 單檔。
2. 程式直接開在自己的視窗，不會打開 Chrome / Edge 分頁，也沒有要保留的黑色命令視窗。
3. 放入圖片，先按「先看局部」比較，滿意再「清理整張圖片」。
4. 完成後按「另存圖片」，選擇儲存位置。
5. 關閉程式視窗即結束。模型已內含，處理圖片無須連網。

Windows 10 / 11 x64，需已安裝 Microsoft Edge WebView2 Runtime。它是應用程式嵌入網頁介面的系統元件；這版用它建立獨立視窗，不是啟動你的 Edge 瀏覽器。Windows 11 內建此元件，多數 Windows 10 也已有。缺少時程式會顯示提示，不會自動下載、安裝或改開外部瀏覽器。

微軟官方 WebView2：https://developer.microsoft.com/microsoft-edge/webview2/

## 新版如何調整

### AI 細緻降噪

先使用已附帶的 SCUNet real-PSNR 模型清理顆粒，再接自引導保邊平滑，清掉模型容易當成真細節而保留的低對比髒紋。

「去紋理力度」設為 0，就只執行 AI。調整去紋理參數後需再按處理；同張圖片、同範圍會重用上一份 AI 結果，避免每次重跑模型。重新載入圖片、改用不同局部範圍或停止處理會影響快取可用性。

### 強力去紋理

直接使用自引導保邊平滑，不跑 AI；這是傳統影像處理，沒有把它冒充成另一個 AI 模型。比第一版固定 5×5 鄰域的快速柔化能處理更大範圍的週期髒紋和斑駁。

- 去紋理力度：0～100。越大，越傾向去除低對比紋理，也越容易減少細筆觸。
- 清理範圍：1～24 px。細顆粒可從 2～6 px 試；較粗髒紋可從 8～16 px 試。
- 效果混合：0～100%。處理完成後可即時調整，降低比例可加回原本細節。

預設力度 60、範圍 8 px、效果混合 100%。覺得太磨皮可先降低範圍與力度，再降低效果混合。

這些是起始值，不是對所有圖片都最佳的參數。沒有你的實際失敗原圖，因此這次只能確認合成髒紋測試改善，不能宣稱你的圖片已達到理想效果。

## 保留與限制

- 原始像素尺寸；單張上限 1,600 萬像素。
- PNG / WebP 保留 alpha；JPG 以白色補底。畫布轉為 sRGB，不保留 EXIF、原始 ICC、HDR、16-bit 色深或動畫。
- 100% 檢視下可拖曳平移；點圖片可變更局部預覽中心。
- 不能可靠分辨所有 AI 假紋理與真正的髮絲、皮膚、畫布筆觸；大範圍重複圖樣或錯誤物件仍可能需要生成式重畫。
- 不是人臉重建、錯誤手指或文字修復工具。

## 隱私與系統元件

程式在本機建立只監聽 127.0.0.1 的內部資產服務，介面由程式視窗中的 WebView2 載入；沒有公開網站、帳號或圖片上傳 API。WebView2 的應用程式資料存於系統使用者快取的 Whetstone/WebView2 目錄，不會與你平常的 Edge 個人設定檔共用。

## PWA 與原始碼

`Export-PWA.cmd` 可將 EXE 中的完整網頁資產和模型匯出到新的 `PWA` 資料夾。這只是檔案匯出，不會替你上傳、註冊或架設任何網站。若目的地已有檔案，匯出會拒絕覆寫。

`source/` 內包含自製處理流程、介面、Windows 視窗與原生另存對話框原始碼。大型模型和 ONNX Runtime 已包含在 EXE，沒有在 ZIP 中重複放置；重建前將匯出的 PWA 資料完整複製到 source/dist。

Go 1.24+ 重建命令（Unix shell 環境變數語法）：

```sh
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -buildvcs=false -trimpath -ldflags="-H windowsgui -s -w" -o Whetstone.exe .
```

`desktop_windows_amd64.syso` 是已附帶的 Windows 圖示與高 DPI manifest 資源。若要重建資源，可使用 `github.com/akavel/rsrc` 及隨附的 icon.ico / app.manifest。

Node.js 測試：`node tests/smoothing.cjs`、`node tests/invariants.cjs`。

## 驗證範圍

Windows x64 GUI 執行檔已成功交叉編譯，Windows 目標的 Go 靜態檢查通過。這個環境沒有 Windows 桌面，尚未實機測試 WebView2 視窗及原生另存對話框；程式層測試不能代替這項驗證。

影像流程已做合成髒紋、輪廓保留、零力度、透明度、特殊尺寸測試，並在測試瀏覽器執行新版平滑與 AI 串接。GPU 路徑仍未實測。
